## 二、第 1 周：答辩准备（7 天）

> 核心理念：答辩只考"一条主线 + 几个追问"，精读 4 个核心文件，其余快速过。

### D1 主线串讲 ⭐核心
- [x] 后端跑起来（`run_server.ps1`）+ 用 `test_chat.ps1` 亲眼看 SSE 事件流（`status → token → product_card → done`）
- [ ] 精读 `server/agent/orchestrator.py` —— **13 步流程**（答辩主心骨）
- [ ] 精读 `server/agent/workflow.py` + `default_handlers.py` —— 6 个 Handler 优先级

**学完标志**：合上代码能口述 13 步，说清 Handler 顺序原因（Clarification 为什么第一、Recommendation 为什么兜底）。

### D2 语义理解层（"怎么听懂用户"）
- [ ] `server/agent/semantic_llm.py` —— 双层规划 5 步：规则→是否要LLM→0.8s预算→合并→校验
- [ ] `server/agent/semantic_rules.py` + `planning_policy.py` —— 规则兜底 + 安全策略

**必答三连问**：为什么不用纯 LLM？（延迟不可控+安全）｜为什么不用纯规则？（覆盖不了长尾）｜LLM 超时怎么办？（`asyncio.timeout`+异常捕获→静默回退规则）

### D3 检索层 + 推荐 Handler（"怎么找到商品"）
- [ ] `server/tools/product_search.py` + `server/rag/retrieval_pipeline.py` —— 粗召回→7 个过滤器→去重+规则加分精排
- [ ] `server/agent/recommendation_handler.py` —— 完整链路：检索→LLM→防幻觉→降级→发卡片

**必答两连问**：为什么 LLM 回答**先缓冲再校验**而不是直接流式？｜失败怎么降级？（`guardrail` 事件+模板回答+卡片照常返回）

### D4 防幻觉 + 状态管理（答辩亮点区）
- [ ] `server/agent/hallucination_guard.py` + `grounding.py` —— 三层检测：存在性/属性事实/SQL
- [ ] `server/session/state.py` + `scope_transition.py` —— 多轮条件累积 + 品类切换清理

**必答**：三层各举一例；`auto_correct / regenerate / fallback` 三种处理场景；"预算500→再要轻量"条件怎么累积。

### D5 快速过剩余能力
- [ ] `server/inputs/multimodal.py`（图片）→ 视觉签名→相似匹配→image_summary
- [ ] `server/agent/commerce_handlers.py`（购物车/对比）+ `bundle_*.py`（场景组合）
- [ ] `server/agent/query_rewriter.py`（三级重写）

**学完标志**：每个功能能讲 1 分钟。

### D6 模拟答辩 🎯
- [ ] 用 `docs/答辩稿.md` + `5分钟实机演示流程.md` 完整串一遍
- [ ] 对着 `annotated/` 高频追问逐条自测

**经典四问必测**：
1. "第二个怎么样"怎么走？（`reference_type=ordinal` → `ContextFollowUpHandler` 取候选第二个）
2. 图片上传怎么处理？（`MultimodalInputProcessor` 视觉签名→相似匹配→image_summary）
3. "再便宜点"条件怎么追加？（`extract_contextual_filters` 追加更低 max_price）
4. "跑鞋"切"手机"旧条件怎么清？（`scope_transition` detect→apply 清理）

### D7 彩排补漏
- [ ] 只复习 D1-D6 答不出的点
- [ ] 完整彩排一遍 5 分钟流程不卡壳

## 三、第 2 周：工程实战（7 天）

> 核心理念：不再逐模块读，用"改代码"倒逼理解，每次改动跑评估脚本回归验证。

| 天 | 实战任务 | 覆盖模块 | 学完标志 |
|---|---|---|---|
| **D8-9** | 改一个 Prompt 规则（如加一条指令）→ 跑 `scripts/evaluate_agent.py` 验证 | `llm/prompt.py` + 评估体系 + SSE 事件 | 理解 LLM 回答怎么生成、评估怎么校验 |
| **D10-11** | **新增一个自定义 Handler**，注册进 `default_handlers.py` | `workflow` 开闭原则 + `tools/registry` + `api/chat.py` | 能独立加功能而不改 orchestrator |
| **D12** | 改幻觉检测 **Layer 2**（加一条属性校验规则）→ 跑 pytest | `hallucination_guard.py` + 测试 | 理解防幻觉三层的判定与降级 |
| **D13** | 新增一个场景 bundle（改 `data/scenario_bundles.json`） | `scenario_*.py` + `bundle_*.py` + 检索 | 理解场景规划→检索→优化→校验链 |
| **D14** | 综合回归 + 复述 | 全部 | 独立回答"加 X 功能要改哪些文件"（对照 `docs/CODE_GUIDE.md`） |
